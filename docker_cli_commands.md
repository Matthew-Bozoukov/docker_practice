# docker_image commands

# docker image COMMAND
build: build an image from a dockerfile
history: show history of an image

import: import contents of  froma  tarbell to create a filesystem image

inspect: display detailed info from one or more images

load: load an image from a tar archive or STDIN

ls: list images

Prune: remove unused images

pull: pull imagefrom a registry

push: push to registry

rm: remove one or more images

save: save one or images to a tar archive streamed to STDOUT by default

docker tag [IMAGE] [TAG-name]


# docker container [command]

exec: run a command in a running container

attach: attach local standard input, output, and error streams to a running container

inspect: inspect info

kill: kill one or more running containers

ls: list the containers

prune: remove all

rm: remove one or more

run: run a command in a new container
